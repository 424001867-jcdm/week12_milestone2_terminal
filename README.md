"For Milestone 2, the IT Hardware Inventory system was architected using an object-oriented paradigm that prioritizes structural scalability, data safety, and maintainable software design. Encapsulation was applied to sensitive inventory pricing fields to prevent unauthorized data corruption, while inheritance and polymorphism enabled clean specialization across different hardware components like processors. Furthermore, robust error handling (`try/catch`) and modular contracts such as abstract audit interfaces and mixins ensure that the system remains resilient against bad inputs. Guided by the principles of *TANGLAW*—fostering technical excellence (*Kahusayan*) and social responsibility—this codebase is designed to protect user data integrity and deliver reliable operational utility for future mobile expansion."
